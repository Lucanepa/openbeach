# OpenBeach

Electronic scoresheet for beach volleyball (teams of two) for the scorer's
tablet: offline first, with referee and livescore views and a LAN venue mode.
It is the beach sibling of [OpenVolley](https://github.com/Lucanepa/openvolley).
Web app: https://beach.openvolley.app

- Source: `escoresheet/frontend` (React + Vite)
- Android app (`com.openvolley.beach`): build steps in
  [`escoresheet/frontend/ANDROID.md`](escoresheet/frontend/ANDROID.md)
